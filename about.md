## About JSON Tools

JSON Tools is a free, open-source web-based JSON parser and editor designed to make working with JSON data effortless and enjoyable.

### Why JSON Tools?

In the modern web development world, JSON (JavaScript Object Notation) has become the de facto standard for data interchange. Whether you're debugging API responses, configuring applications, or exploring data structures, you need a tool that's:

- **Fast**: No installation, no registration—just open and use
- **Reliable**: Built on the battle-tested [JSONEditor](https://github.com/josdejong/jsoneditor) library
- **Beautiful**: Clean, modern interface that works on any device
- **Private**: Everything runs in your browser—your data never leaves your machine

### Features

- **Dual-pane interface**: Edit and view simultaneously
- **Multiple view modes**: Tree, code, form, and text views
- **Real-time validation**: Instant feedback on JSON syntax
- **Syntax highlighting**: Easy-to-read color-coded JSON
- **Responsive design**: Works perfectly on desktop, tablet, and mobile
- **Keyboard shortcuts**: Power-user features for efficiency
- **Zero dependencies**: Pure static site, blazing fast

### Technology

This project is built with:

- **[Jekyll](https://jekyllrb.com/)**: Static site generator for speed and simplicity
- **[JSONEditor](https://github.com/josdejong/jsoneditor)**: Powerful JSON editing component by [Jos de Jong](https://github.com/josdejong)
- **Modern web standards**: HTML5, CSS3, and vanilla JavaScript
